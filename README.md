# 🏦 Bank Management System

A Java-based Bank Management System developed using Object-Oriented Programming (OOP) concepts. This project provides a simple banking environment where users can create accounts, deposit and withdraw money, check balances, and view transaction history.

The application also includes administrative functionality and file-based data persistence to store account information.

## ✨ Features

- **User Login:** Access banking operations through user authentication.
- **Admin Login:** Administrative access to manage banking operations.
- **Account Creation:** Create and manage bank accounts.
- **Deposit Money:** Add funds to an existing account.
- **Withdraw Money:** Withdraw money while checking available balance.
- **Balance Inquiry:** Check current account balance.
- **Savings Account Interest:** Calculate interest for savings accounts.
- **Transaction History:** View account transaction records.
- **Admin Dashboard:** Access administrative banking functions.
- **File-Based Data Persistence:** Store account information using Java file handling and serialization.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Serialization
- File Handling
- Exception Handling

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Install Java

Install Java Development Kit (JDK) 14 or later.

Check your Java installation:

```bash
java -version
javac -version
```

### 2. Clone the Repository

```bash
git clone https://github.com/Nishantkscode/Bank-management-system.git
```

### 3. Move into the Project Directory

```bash
cd Bank-management-system
```

### 4. Compile the Application

```bash
javac BankSystem.java
```

### 5. Run the Application

```bash
java BankSystem
```

The application will start in your terminal.

## 🧠 Object-Oriented Programming Concepts

This project demonstrates important Java OOP concepts:

- **Encapsulation:** Organizing account data and related operations within classes.
- **Inheritance:** Reusing common account functionality through account types.
- **Abstraction:** Separating essential banking operations from implementation details.
- **Polymorphism:** Supporting different account behaviors where applicable.

## 💾 Data Persistence

The application uses Java file handling and serialization to store account information.

This allows account data to remain available between application sessions.

## 🔐 Security Note

This project is developed for educational purposes and demonstrates basic banking operations using Java.

It is not intended for real-world financial transactions.

Production banking systems require secure authentication, encrypted data storage, access controls, secure transaction processing, and additional security measures.

**Important:** Do not use real banking credentials or personal financial information in this project.
