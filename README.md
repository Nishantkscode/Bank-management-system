# 🏦 Bank Management System

A Java-based Bank Management System developed using Object-Oriented Programming (OOP) concepts.

## 👨‍💻 Developer
**Nishant Kumar**

## 🚀 Features
- User Login and Admin Login
- Create and Manage Bank Accounts
- Deposit and Withdraw Money
- Check Account Balance
- Savings Account Interest Calculation
- Transaction History
- Admin Dashboard
- File-Based Data Persistence

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Serialization
- File Handling
- Exception Handling

## 📂 Project Structure
- `BankSystem.java` – Main application and account management logic
- `.gitignore` – Excludes compiled files and account data
- `nextId.txt` – Stores the next account ID

## ▶️ How to Run

1. Install Java JDK 14 or later.
2. Clone this repository:

```bash
git clone https://github.com/Nishantkscode/Bank-management-system.git
```

3. Open the project folder.
4. Compile the application:

```bash
javac BankSystem.java
```

5. Run:

```bash
java BankSystem
```
